# Selenium Practice — jetbrains.com

> 📚 **Learning project** — part of my QA automation practice.

UI tests of the [jetbrains.com](https://www.jetbrains.com) main page written in **Java with Selenium WebDriver and JUnit 5**, using the Page Object Model pattern, built with Maven.

## Focus of this exercise

- Selenium WebDriver setup (ChromeDriver, implicit waits)
- Page Object Model basics
- JUnit 5 lifecycle (`@BeforeEach`, `@AfterEach`)

## How to run

```bash
mvn clean test
```
